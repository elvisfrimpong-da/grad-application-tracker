Connect your Gmail

Not connected in this session.

GradPath requests read-only access to your Gmail. Matching happens in this browser. Saved updates are encrypted with your tracker. It checks for mail while this page is open; reconnect after closing the page or when Google access expires.

One-time Google setup
  1. Create a Google Cloud project and enable the Gmail API.
  2. Set the OAuth consent audience to External and Testing, add your Google account as a test user, and add the Gmail read-only scope in Data Access.
  3. Create a Web application OAuth client. Add https://elvisfrimpong-da.github.io as an authorized JavaScript origin.
  4. Paste the client ID below and save it. Then select Connect Gmail and approve read-only access.

Google may show an unverified-app warning for a personal testing project. You control the project and may review the requested permission before continuing. Google's setup guide ↗
